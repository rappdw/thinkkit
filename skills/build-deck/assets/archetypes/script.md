# Talk script (verbatim source of truth)

The build's QA diffs every spoken notes paragraph against this file. Keep the notes
fragments and this script identical, sentence for sentence. Edit both together.

## title

Open with the one sentence that tells them why this matters to them, not to you.

Introduce yourself in a line: name, role, and the single credential that earns you the next twenty minutes.

## chart

Put the landscape on one axis so the audience stops arguing about definitions and starts placing things.

Name the shift that happened recently, and why it changes what is now possible.

Leave them with the test: for any claim, ask where it sits on this spectrum.

## table

Here are the criteria that decide whether this approach fits a given problem.

Score the first candidate out loud, one row at a time, so they learn the test by watching you run it.

Score a second candidate that fails one criterion, so the test has teeth.

## ladder

Autonomy is a ladder, not a switch, and each rung earns the next.

Most real deployments live on the lower rungs, and that is a feature, not a limitation.

## timeline

Walk the story as a timeline so the payoff has a shape.

Keep each phase to one plain beat so the arc stays legible from the back of the room.

Land the phase they will not believe, then let it sit for a second.

Mark the moment the work changed hands, because that is the real result.

## closing

Restate what the audience is walking out with, in the vocabulary you gave them.

End on the one instruction you want them to act on tomorrow.
